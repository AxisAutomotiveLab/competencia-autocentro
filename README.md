# Competencia · Ofertas y Precios — Autocentro

Dashboard de ofertas de la competencia (anuncios en Meta y precios publicados en los websites de los dealers), separado por marca.

| Marca | Página |
| Nissan | `nissan.html` |
| Toyota | `toyota.html` |
| Chrysler / Jeep / Dodge / Ram | `chrysler.html` |
| Las 3 marcas juntas | `index.html` |

Los datos vienen de las hojas de Google "Competencia – Autocentro" (una por marca) a través de un Apps Script. Los websites se actualizan solos todos los días; las ofertas de Meta se actualizan cuando se leen de la Biblioteca de anuncios.
